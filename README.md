## Project Unggulan

**Aplikasi Administrasi Keuangan Gudang Sawit** — aplikasi laporan laba rugi untuk gudang TBS yang dirancang dari pengalaman langsung sebagai krani timbang:

- Pembelian dan penjualan per kategori: Buah 1, Buah 2, dan Brondolan
- Buah pulangan ditimbang ulang di gudang dan dibandingkan dengan berat pabrik sebagai kontrol selisih
- Laba rugi per periode tutup buku (peron kosong) dan laba rugi per motor untuk pola muat langsung
- Konsep hitung — potongan, tarif SPSI, perlakuan Buah 2, biaya operasional — dapat diatur untuk setiap pemilik gudang, karena setiap gudang punya konsep hitung sendiri

**Aplikasi Timbangan Gudang & PKS** — aplikasi jembatan timbang yang saya rancang dari awal sampai akhir untuk gudang TBS dan pabrik kelapa sawit (PKS): penimbangan bruto/tara/netto, tiket timbang, dan pelaporan.
